# 和弦谱复刻（8pu 功能谱）v1 实施方案

## 目标与范围（已按你的裁定）
复刻 8pu **和弦谱**（纯和弦进行 + 节奏型，无旋律），最终一键生成指板动图。格子功能谱版式先行（通用乐谱版式后补）。

**做**：每拍和弦位 / 级数⇄音名双模式 / 键盘优先输入（数字 1-7 级数、C 面板、B 低音、R 节奏型、⌫ 删、0 休止、- 延音、反拍拆分）/ 小节操作（加删/换行/每行 N 小节重排/小节线/反复/跳房子/段落标记/按小节歌词）/ 播放（木吉他和弦+节奏型、节拍器、速度、光标跟随、指板舞台同步）/ 移调看谱 / MusicXML 导入导出 / **生成动图 → 进动态模式精修导出**。
**不做（v1）**：旋律/简谱排版、多声部、虚拟钢琴、MIDI 键盘、自由拖动标注、链接分享、云同步、MIDI 导出、跳过小节。

## 数据模型（localStorage: `fretboard-chordcharts`，照 clipModel 模式带滚动备份）
```
song = { id, name, createdAt, updatedAt,
  key: { root: 0-11(C基), minor: false }, timeSig: 4, bpm: 70,
  display: 'degree'|'name', rowsPerLine: 4,
  measures: [{ id, section?, lyrics?, barline?, house?,
               slots: [ { kind:'chord'|'rest'|'hold',
                          chord?: { degree:1-7, acc, quality, bass? },
                          split?: [槽,槽], rhythm? } × 拍数 ] }] }
```

## 新文件（6 个 + 2 组件）
1. `src/utils/chordLib.js` — 和弦库：调内默认质量表（大调 1/4/5 大三、2/3/6 小三、7 减；小调同构）、quality→音程集合→MIDI 音高、级数/音名/转位双向格式化（复用 songStructure 的 parseChordToken/chordDisplay）
2. `src/utils/chordChartModel.js` — 歌曲 CRUD + localStorage + 滚动备份（照 clipModel.js:19-33 模式）
3. `src/utils/voicing.js` — 和弦→吉他按法：开放和弦表（C D E F G A A7 Dm Em Am 等 14 个）+ 可移动把位（6 弦根 E 型 / 5 弦根 A 型 × quality 形状）；输出指板位置集 + 自动品窗
4. `src/utils/chartPlayback.js` — 播放引擎：展开反复/跳房子→线性拍序列；节奏型→低音+扫弦/分解事件；节拍器；拍时钟
5. `src/utils/musicxmlChart.js` — MusicXML 导入导出（harmony/key/time/barline/repeat/words；DOMParser 手写，无新依赖；导入忽略旋律声部）
6. `src/components/ChordChartView.jsx` — 主页面（`#/chords` 路由）：谱头（标题/1=C/拍号/BPM/级数⇄音名/移调/导入导出/生成动图）+ 格子谱面 + 播放条 + 指板舞台
7. `src/components/ChordPanel.jsx` — 和弦全库面板 / 低音选择 / 节奏型选择弹出层
8. CSS `cc-*` 块追加到 fretboard.css；i18n zh/en 追加块

## 接线（全部有现成模式）
- App.jsx 加 `#/chords` 路由（照 `#/dynamic` 先例，App.jsx:13-17）
- FretboardMenu 入口按钮（复用残留的 scoreView/scoreViewTitle i18n key）
- **audioService 从孤儿接线**：挂载 init / 卸载 dispose（Tone.js 木吉他采样 + 三角波兜底都写好了）
- 动图出口：构造 clip（出生帧色用 colorConfig 导出的 `frameTintFromData` 烙印，照 useDynamicMode.js:453-467 的 persistClip 逻辑；同弦移动自动标 sl 对）→ `saveClip` → 跳 `#/dynamic?c=<id>`（Fretboard.jsx:229-248 已支持 ?c= 续编）
- 播放时舞台用 ScorePieces.ScoreBoard 渲染当前拍帧（clip 帧包 `{state: frame}`，照 renderBoardImage 的用法）

## 实施顺序（每步可验证）
1. chordLib + chordChartModel + `scripts/smoke-chords.mjs`（级数⇄音名往返、调内默认表、模型 CRUD）
2. voicing + 测试不变量（按法所有音∈和弦音、品距≤4、根音在低音弦、移调平移正确）
3. ChordChartView 静态版：路由 + 谱头 + 格子渲染 + 存储（能建/存一首歌）
4. 键盘编辑 + ChordPanel + 反拍拆分/延音/休止 + 小节操作全套（含反复/跳房子/段落）
5. 播放：chartPlayback + audioService 接线 + 节拍器 + 光标高亮 + 指板舞台同步
6. 移调看谱（级数不动，音名/播放/指板重算）
7. MusicXML 导入导出 + 往返测试
8. 生成动图端到端：照打 8pu《送别》和弦谱（8pu.cn/s/7ifzsuuv 的进行）→ 播放 → 生成动图 → 动态模式导出 GIF
9. 文档：INTERACTION_GUIDE.md 增章、8PU_INTEGRATION.md 更新

## 风险与对策
- Tone.js 采样走 CDN：audioService 已有三角波兜底，不新增依赖
- MusicXML harmony kind 词表有限：quality→kind 映射表覆盖全库，超集降级为文本记号
- 反复×跳房子组合按常见惯例实现（房子1→反复→跳过进房子2），嵌套反复不支持
- 无新 npm 依赖；全部纯前端，离线可用

- smoke-chords.mjs 全绿（chordLib/voicing/反复展开/MusicXML 往返，照 smoke-core.mjs 的 38 断言模式）
